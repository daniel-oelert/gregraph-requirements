# Kind-rule violations are refused with the rule named

## Statement
WHEN a link is requested whose source or target kind violates the edge type's kind rule, the tool shall refuse the link and name the rule.

## Rationale
Kind rules encode the modelling language; naming the rule teaches the user the intended structure.
