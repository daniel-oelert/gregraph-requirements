# origin_cr and introduces are recorded with --cr

## Statement
WHEN a document is created or superseded with `--cr`, the tool shall record the change request in the new document's `origin_cr` and add the document's ID to the change request's `introduces` list.

## Rationale
Traceability from a requirement back to the change request that introduced it must be recorded automatically.
