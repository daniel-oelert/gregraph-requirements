# Manage requirements as a Git-synchronised DAG

## Goal
The tool shall let a requirements engineer manage requirements as a directed acyclic graph of atomic Markdown documents, synchronised only through Git.

## Rationale
A versioned DAG kept in Git gives the team a reviewable, offline requirements model with no server to run and no second source of truth.
