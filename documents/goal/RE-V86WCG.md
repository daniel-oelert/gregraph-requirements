# Tool-owned structure, human-owned prose

## Goal
The tool shall ensure that humans edit only Markdown prose and configuration, while all structure (files, identifiers, metadata, links, versions) is owned by the tool.

## Rationale
Keeping structure in tool-owned sidecars prevents drift and merge conflicts in metadata, while authors keep editing familiar Markdown.
