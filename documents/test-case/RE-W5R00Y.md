# Verify: documents are stored as Markdown plus JSON sidecar

## Objective
Verify the on-disk shape of a document.

## Preconditions
An initialised repository.

## Steps
Create a document and list the files written for it.

## Expected result
Exactly one Markdown file and one JSON sidecar exist for the document, both with the identifier as filename stem.
