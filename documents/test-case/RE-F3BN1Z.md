# Verify: identifiers are never reused

## Objective
Verify that no identifier is ever reused, including identifiers of deprecated and superseded documents.

## Preconditions
A repository containing a deprecated document and a superseded document.

## Steps
Create new documents and compare their identifiers with every existing identifier, including the retired ones.

## Expected result
No new identifier equals any existing identifier.
