# Verify: graph emits a styled Mermaid flowchart

## Objective
Verify that `gregraph graph` emits a Mermaid flowchart with node shapes by kind and edge styles by type.

## Preconditions
A repository with documents of several kinds linked by several edge types.

## Steps
Run `gregraph graph`.

## Expected result
The output is a fenced Mermaid flowchart whose node shapes follow the kinds and whose edge styles follow the edge types.
